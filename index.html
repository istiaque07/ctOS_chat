About ctOS Architecture

ctOS হলো একটি সম্পূর্ণ ডিসেন্ট্রালাইজড (P2P) চ্যাট অ্যাপ্লিকেশন। এটি WebRTC DataChannels ব্যবহার করে সরাসরি ডিভাইস-টু-ডিভাইস চ্যাট পরিচালনা করে।

Architecture Specs:

• Signaling: PeerJS Cloud / STUN servers.

• Encryption: Direct DTLS/SRTP DataChannels.

• Zero Storage: No cloud database persistence.
